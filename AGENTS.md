# Agent Instructions

## Mission

Build AgentHQ into a safe, portable operating layer for a three-agent software
team managed through Paperclip.

## Required reading

Before changing code, read:

1. `docs/PROJECT_CONTEXT.md`
2. `docs/DECISIONS.md`
3. `docs/TASKS.md`
4. `docs/SECURITY.md`
5. Your assigned role in `agents/`

## Working rules

- Work on one assigned task only.
- Do not edit files outside this repository.
- Do not add credentials, tokens, passwords, or private account files.
- Do not deploy, publish, merge, or purchase anything.
- Do not bypass approval or sandbox controls.
- Use a branch for every implementation task.
- Add or update tests for behavior changes.
- Record lasting decisions in `docs/DECISIONS.md`.
- Stop and ask Yusuf when the task changes scope or requires external access.

## Definition of done

A task is done only when its acceptance checks pass, tests pass, QA records
evidence, no unrelated files changed, and Yusuf approves the merge.
