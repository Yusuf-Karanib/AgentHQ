# Roadmap

## Milestone 1 — Foundation

- Durable context files
- Role separation
- Safe manifest
- Validator and automated tests
- Portable context compiler
- GitHub CI

## Milestone 2 — Paperclip pilot

- Pinned local Paperclip release
- One company and one AgentHQ project
- Lead, Builder, and QA created
- Sequential task handoff
- Human approval before merge
- Cost and run limits tested

## Milestone 3 — Portfolio evidence

- Pull-request workflow
- QA reports attached to tasks
- Audit and cost summary export
- Short recorded demonstration
- Public architecture and security explanation

## Milestone 4 — Second real project

Connect one selected project only after AgentHQ completes three controlled tasks
without unsafe actions, missing context, or uncontrolled spending.
